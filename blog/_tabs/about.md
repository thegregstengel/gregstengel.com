I'm a staff infrastructure engineer. I've spent about two decades in infrastructure, most of it in AWS, with some Azure and GCP along the way. For a long stretch I worked for cloud service providers, which means I got to see how a lot of different teams build, break, and rebuild their infrastructure.

I like building things that work and figuring out why things don't. This blog is where I write about things I've built, problems I've picked apart, and the stuff I learned along the way that I wish someone had written down for me. I try to keep it practical. If I'm writing about it, I've probably done it, and I'll show you the rough edges too.

The tinkering doesn't stop when work does. These days coding agents do a lot of the typing, which is how one person ends up with this many side projects:

- **[Big Bang Smugglers](https://bigbangsmugglers.com)**, a turn-based space trading game in the spirit of the old BBS door games.
- **[Clickarr](https://clickarr.net)**, an open-source app that turns a Plex or Jellyfin library into TV channels.
- **[Protovision Games](https://protovisiongames.com)**, the studio name the games ship under.
- **A Sesame Robot**, built with my son. [That one has its own post]({% post_url 2026-10-25-building-a-sesame-robot-with-my-son %}).

There is also a Plex media server backed by TrueNAS for the household. Most of my side projects start the same way: "I wonder if I could..." followed by late nights and weekends I'll never get back.

When I'm not in a terminal, I'm spending time with my family and my dog, Dre, who has zero interest in any of this but strong opinions about walks.

There's more about the day job at [gregstengel.com](https://gregstengel.com).
