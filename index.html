    Datacenters, colo, and a hundred web servers. Linux, VMware, Apache, WebSphere, IIS — keep it running, figure out what broke, write it down. Then OpenStack deployments with Ansible, because clicking through infrastructure gets old fast.

  2. 02

    Making the noise useful

    Built Splunk across three datacenters and 2,500+ nodes, with Puppet handling the forwarders. Went deep on clustered deployments, custom integrations, and dashboards people actually used. Later, built out Elastic Cloud observability. Collecting everything is easy; making it useful is the job.

  3. 03

    Building it. Leading it.

    Architected cloud environments, then led the engineers keeping them alive. AWS first, Azure and GCP too. Terraform, backup automation, migrations, fewer noisy alerts, and fewer recurring bills. Kept my hands in the tooling even when the calendar filled with meetings.

  4. 04

    Platform & identity

    Multi-account AWS, EKS across three regions, and the plumbing between Okta, Identity Center, Kubernetes RBAC, and ArgoCD. Terraform/Terragrunt through GitLab CI, Vault for secrets, tighter KMS policies. Make the right access easy and the wrong access difficult.

  5. 05

    Less toil, more shipping

    Python, Bash, Lambda, EventBridge — whatever gets the repeat work off somebody’s plate. Lately, AI agents too, helping turn weeks of delivery into days. Still responsible for what ships. Still writing the runbooks.

// signature builds

  1. Multi-datacenter Splunk platform

    Built Splunk across three datacenters and 2,500+ nodes. Puppet handled forwarder rollout; scripts handled new index configuration. Less hand configuration, fewer opportunities to get creative by accident.

  2. Monitoring that earns its keep

    Built a clustered Splunk platform in AWS to monitor customer environments. Custom integrations, 50+ dashboards per customer app, and summary indexing turned scattered resource data into useful answers.

  3. AWS security monitoring pipeline

    Built a CloudFormation stack to send AWS security logs and events through Kinesis Firehose into Splunk HEC, with SNS notifications. Covered root logins, unauthorized API calls, and IAM and network changes. Fewer places to look when something looked wrong.

  4. Backup & compliance automation

    Automated AWS backups and compliance checks with CloudFormation, AWS Config, Cloud Custodian, and tagging standards. Replaced third-party backup tooling with native AWS Backup, taking thousands out of recurring costs.

  5. Hybrid file-sync pipeline

    Connected SFTP and SMB workflows across AWS and on-prem using Lambda, S3, and DynamoDB. Automated file mapping and sync so moving files didn’t need to be somebody’s job.

  6. Fewer IPs, smaller bills

    Built automation to migrate and consolidate public IPs, reducing per-application IP costs. Small pieces of infrastructure add up when the meter never stops.

  7. Identity modernization

    Replaced legacy IAM access with Okta-backed Identity Center across a multi-account AWS environment. Reusable Terraform/Terragrunt modules and GitLab CI made permission changes repeatable. Least privilege, maintained in code.

  8. Multi-region EKS access

    Operated EKS across three AWS regions, connecting Identity Center access to Kubernetes RBAC and ArgoCD deployments. Managed Vault secrets and ingress alongside it, with runbooks so the access path didn’t live in one person’s head.
